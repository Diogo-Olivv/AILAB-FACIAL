# Suporte

Este é um projeto de código aberto mantido por voluntários e por um laboratório de extensão. Não há SLA de suporte.

## Onde pedir ajuda

| Precisa de | Onde |
|---|---|
| Entender como rodar o projeto | README e `docs/tutorials/` |
| Resolver um problema de uso | Issue com o template "Dúvida / suporte" |
| Reportar um bug | Issue com o template de bug |
| Sugerir uma funcionalidade | Issue com o template de funcionalidade |
| Reportar uma vulnerabilidade | [SECURITY.md](SECURITY.md), nunca issue pública |
| Tratar dados pessoais | Encarregado do laboratório (ver [GOVERNANCE.md](GOVERNANCE.md)) |

## Antes de abrir uma issue

- Verifique se já existe uma issue igual.
- Veja a seção de perguntas frequentes em `docs/faq.md`.
- Inclua versão (commit ou tag), passos de reprodução e o que você esperava.
- Remova dados pessoais, imagens, tokens e chaves do que você colar.

## Versões suportadas

Apenas a `master` recebe correções. Consulte [SECURITY.md](SECURITY.md) para a política de segurança.
